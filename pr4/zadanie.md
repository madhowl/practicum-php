# Работа 4. Каталог товаров — файлы и JSON

## Цель

Вынести каталог из PHP-массива в JSON-файл `data/catalog.json` и научить
приложение загружать/сохранять данные. Товары, добавленные через форму,
теперь **реально сохраняются** на диске.

## Задание

Создайте слой «модель» (в `model.php`) — функции работы с файлом:

1. `default_catalog(): array` — каталог «заводских настроек» из 8 товаров.
   Каждый товар теперь с полем `id` (от 1 до 8).

2. `save_catalog(array $catalog, string $file = CATALOG_FILE): bool`
   Сериализует каталог в JSON (флаги `JSON_PRETTY_PRINT | JSON_UNESCAPED_UNICODE`)
   и пишет в файл с блокировкой `LOCK_EX`. Возвращает `false` при ошибке.

3. `load_catalog(string $file = CATALOG_FILE): array`
   Возвращает массив товаров **в любой ситуации**, восстанавливая дефолтный
   каталог, если:
   - файла нет или он не читается;
   - `file_get_contents` вернул `false`;
   - `json_validate($json)` не прошёл;
   - результат `json_decode(..., true)` — не список (не подходит
     `array_is_list()`).
   Испорченный файл переименовывайте в `<файл>.broken.<дата>`, а не удаляйте.

4. `catalog_stats(array $catalog): array` — сводка: число товаров, суммарный
   остаток, стоимость склада (для «шапки» страницы).

5. Постоянная `CATALOG_FILE = __DIR__ . '/data/catalog.json'`.

6. В `index.php`:
   - данные берутся из `load_catalog()`, а не из PHP-файла;
   - форма добавления (работа 3) теперь реально сохраняет товар: новый `id`
     выдаёт функция `next_id()`, затем `save_catalog()`;
   - после успешного сохранения — редирект `header('Location: index.php?added=1')`
     (PRG), сообщение об успехе выводится по `?added=1`;
   - внизу покажите служебную строку: путь к файлу, размер, дата изменения.

## Пометки

- Данные, которые вернула форма, в файл писать как есть (в «сыром» виде),
  а экранировать при выводе в HTML.
- Не удаляйте товары случайно при автотестах: `test.php` работает только
  с временными файлами в `sys_get_temp_dir()`.
- Валидацию и функции-помощники (`search_by_name`, `filter_by_category`,
  `validate_product`, `sanitize_product`, `e`) держите в `functions.php`.

## Запуск

```bash
php test.php                    # автотесты
php -S localhost:8000 -t pr4    # браузер
```

## Критерии приёмки

- [ ] `php test.php` завершается с «ошибок: 0»;
- [ ] после добавления товара через форму в `data/catalog.json` появляется запись,
      а после перезагрузки страницы товар виден в таблице;
- [ ] если удалить `catalog.json` вручную и обновить страницу — файл
      пересоздаётся с дефолтным каталогом, ошибки нет;
- [ ] если записать в файл мусор и обновить страницу — каталог
      восстанавливается, рядом появляется файл `<файл>.broken.*`;
- [ ] на странице видны путь, размер и дата изменения файла.
