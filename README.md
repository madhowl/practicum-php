# Практикум по PHP 8.3: от процедурного кода к ООП и MVC

7 практических работ по основам PHP. Работы 1–5 — в **чисто процедурном стиле**
(без ООП), работа 6 переводит проект на **объекты**, работа 7 знакомит с **MVC и
FrontController**. Каждая работа — самостоятельный, проверяемый этап; вместе они
образуют два учебных проекта: каталог товаров и сайт-визитку студии с новостями.

## Требования

- PHP **8.3** и выше (`php -v`)
- расширение `mbstring` (`php -m | grep mbstring`)
- **Composer** (`composer --version`) — нужен для работ 6 и 7: он генерирует
  автозагрузку классов по правилу PSR-4 и устанавливает зависимости
  (`composer install` в папках `pr6` и `pr7/solution`).
  Фреймворки и база данных не требуются.

## Структура

```
pr1/  Основы языка            переменные, типы, условия, match, циклы; таблица каталога
pr2/  Массивы и функции       фильтры, поиск, сортировки, пагинация
pr3/  Строки и формы          GET/POST, валидация, безопасный вывод; форма добавления
pr4/  Файлы и JSON            json_encode/decode, json_validate (новое в 8.3), load/save, ошибки
pr5/  Финальный CRUD          добавление/редактирование/удаление + поиск + пагинация
pr6/  ООП                    классы, инкапсуляция, enum, интерфейсы, исключения, автозагрузка
pr7/  MVC и FrontController  модель, представление, контроллер, PSR-7, League Route, шаблоны
```

В каждой папке:

- `teoria.md` — краткий конспект с примерами;
- `zadanie.md` — задание и критерии приёмки;
- решение: `solution.php` (CLI) или страницы `index.php`, `add.php`, … (браузер);
- `test.php` — автотесты (`php test.php`).

В работе 6 классы лежат в `pr6/src/` (их пишет студент), автозагрузку по правилу
PSR-4 генерирует Composer из `pr6/composer.json`, а автотесты берут классы оттуда.

В работе 7 студенческая заготовка находится в `pr7/` (`src/` и `templates/` создаёт
студент), а полное эталонное решение — в `pr7/solution/`. Автотесты по умолчанию
ищут классы в `pr7/src/`; чтобы проверить эталон, укажите автозагрузчик явно:

```bash
PR7_AUTOLOAD=solution/vendor/autoload.php php pr7/test.php
```

## Как запускать

**Работы 6 и 7** перед первым запуском требуют установки зависимостей:

```bash
cd pr6
composer install      # создаёт vendor/autoload.php (правило PSR-4)

cd ../pr7/solution
composer install      # league/route, laminas-diactoros и автозагрузка
```

**Тесты** (после каждого этапа):

```bash
php pr1/test.php
php pr2/test.php
php pr3/test.php
php pr4/test.php
php pr5/test.php
php pr6/test.php
PR7_AUTOLOAD=solution/vendor/autoload.php php pr7/test.php
```

В конце должно быть «ошибок: 0». Код завершения `0` — успех, `1` — есть провалы.

**Сайт** (работы 3–7 — веб-страницы):

```bash
php -S localhost:8000 -t pr3               # работа 3: формы и валидация
php -S localhost:8000 -t pr4               # работа 4: каталог из JSON + сохранение
php -S localhost:8000 -t pr5               # работа 5: полное приложение (CRUD)
php -S localhost:8000 -t pr6               # работа 6: то же приложение на классах
php -S localhost:8000 -t pr7/solution/public  # работа 7: сайт-визитка на MVC
```

Открыть в браузере: `http://localhost:8000/index.php` (работы 3–6) или
`http://localhost:8000/` (работа 7).

**Консольные демо** (работы 1–2):

```bash
php pr1/solution.php             # таблица каталога с расчётом скидок и итогов
php pr2/solution.php             # демо фильтров, поиска, сортировки, пагинации
```

## Идеи для развития (по желанию)

- экспорт каталога в CSV (`fputcsv`);
- корзина покупателя на `$_SESSION`;
- загрузка изображения товара (`$_FILES`) с проверкой типа файла;
- сортировка в две стороны кликом по заголовку таблицы;
- «ноль остатка» скрывается из витрины отдельным фильтром;
- для работы 6: альтернативное хранилище (CSV или SQLite) через `StorageInterface`;
- для работы 6: `DataMapper` вместо `fromArray`/`toArray` в классе `Product`;
- для работы 7: поиск, фильтр, пагинация и CRUD новостей;
- для работы 7: PSR-15 middleware для логирования запросов.

Все данные, которые приложение создаёт, находятся в `pr4/data/catalog.json`,
`pr5/data/catalog.json` и `pr6/data/catalog.json`. Если файл удалить или испортить —
приложение само восстановит каталог по умолчанию. Mock-новости работы 7 лежат в
`pr7/solution/data/news.json` и доступны только для чтения в основной реализации.
