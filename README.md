# Практикум по PHP 8.3: сквозной проект «Каталог товаров»

5 практических работ по основам PHP в **чисто процедурном стиле** (без ООП).
Каждая работа — самостоятельный, проверяемый этап; все вместе образуют одну
сквозную тему — веб-витрину «Каталог товаров» с хранением данных в JSON-файле.

## Требования

- PHP **8.3** и выше (`php -v`)
- расширение `mbstring` (`php -m | grep mbstring`)
- ничего больше не нужно: без composer, без фреймворков, без БД

## Структура

```
pr1/  Основы языка            переменные, типы, условия, match, циклы; таблица каталога
pr2/  Массивы и функции       фильтры, поиск, сортировки, пагинация
pr3/  Строки и формы          GET/POST, валидация, безопасный вывод; форма добавления
pr4/  Файлы и JSON            json_encode/decode, json_validate (новое в 8.3), load/save, ошибки
pr5/  Финальный CRUD          добавление/редактирование/удаление + поиск + пагинация
```

В каждой папке:

- `teoria.md` — краткий конспект с примерами;
- `zadanie.md` — задание и критерии приёмки;
- решение: `solution.php` (CLI) или страницы `index.php`, `add.php`, … (браузер);
- `test.php` — автотесты (`php test.php`).

## Как запускать

**Тесты** (после каждого этапа):

```bash
php pr1/test.php
php pr2/test.php
php pr3/test.php
php pr4/test.php
php pr5/test.php
```

В конце должно быть «ошибок: 0». Код завершения `0` — успех, `1` — есть провалы.

**Сайт** (работы 3–5 — веб-страницы):

```bash
php -S localhost:8000 -t pr3     # работа 3: формы и валидация
php -S localhost:8000 -t pr4     # работа 4: каталог из JSON + сохранение
php -S localhost:8000 -t pr5     # работа 5: полное приложение (CRUD)
```

Открыть в браузере: `http://localhost:8000/index.php`

**Консольные демо** (работы 1–2):

```bash
php pr1/solution.php             # таблица каталога с расчётом скидок и итогов
php pr2/solution.php             # демо фильтров, поиска, сортировки, пагинации
```

## Идеи для развития (по желанию)

- экспорт каталога в CSV (`fputcsv`);
- корзина покупателя на `$_SESSION`;
- загрузка изображения товара (`$_FILES`) с проверкой типа файла;
- сортировка в две стороны кликом по заголовку таблицы;
- «ноль остатка» скрывается из витрины отдельным фильтром.

Все данные, которые приложение создаёт, находятся в `pr4/data/catalog.json`
и `pr5/data/catalog.json`. Если файл удалить или испортить — приложение
само восстановит каталог по умолчанию.
