## Переменные и типы данных

Переменная начинается с `$`. PHP умеет сам определять тип значения:

```php
$name  = 'Ноутбук';          // строка (string)
$price = 54990;              // целое число (int)
$part  = 10.5;               // дробное число (float)
$inStock = true;             // логическое (bool): true / false
$nothing = null;             // пусто (null)
$items = ['a', 'b'];         // массив (array)
```

Проверить тип можно функцией `var_dump($value)` — полезная штука во время отладки.

## Операторы

```php
$a = 7 + 2;   // 9    сложение
$a = 7 - 2;   // 5    вычитание
$a = 7 * 2;   // 14   умножение
$a = 7 / 2;   // 3.5  деление
$a = 7 % 4;   // 3    остаток от деления
$a = 2 ** 3;  // 8    возведение в степень

$a++;         // увеличить на 1 (то же, что $a = $a + 1)
$a--;         // уменьшить на 1
```

Сравнение и логика:

```php
$a ==  $b     // равно (без проверки типа)
$a === $b     // строго равно (значение И тип)
$a !=  $b     // не равно
$a !== $b     // строго не равно
$a < $b, $a > $b, $a <= $b, $a >= $b
$result = $a && $b;   // логическое И (оба истинны)
$result = $a || $b;   // логическое ИЛИ (хотя бы одно истинно)
$result = !$a;        // отрицание
```

## Условия

```php
if ($stock === 0) {
    echo 'Нет в наличии';
} elseif ($stock <= 5) {
    echo 'Мало';
} else {
    echo 'В наличии';
}
```

`switch` — удобен, когда одно выражение сравнивается с несколькими значениями:

```php
switch ($category) {
    case 'Техника':
        $icon = '💻';
        break;
    case 'Игры':
        $icon = '🕹️';
        break;
    default:
        $icon = '📦';
}
```

## match — «умный switch» из PHP 8

Не требует `break`, возвращает значение и умеет условия:

```php
$label = match (true) {
    $stock === 0 => 'Нет в наличии',
    $stock <= 5  => 'Мало',
    default      => 'В наличии',
};
```

## Циклы

```php
// Пока условие истинно
while ($i < 3) { $i++; }

// Цикл со счётчиком
for ($i = 0; $i < 3; $i++) { ... }

// По элементам массива — самый частый цикл
foreach ($catalog as $product) { ... }

// foreach с ключом
foreach ($catalog as $index => $product) { ... }
```

Управление циклом: `break;` — выйти, `continue;` — перейти к следующей итерации.

## Функции

```php
function price_with_discount(int $price, int $discount): float
{
    return round($price * (100 - $discount) / 100, 2);
}
```

- параметры с типами `int`, `float`, `string`, `array`…;
- `: float` после скобок — тип возвращаемого значения;
- `return` возвращает значение (без `return` функция вернёт `null`).

Заметка по заданию: у функции своя область видимости — переменные, объявленные внутри,
снаружи не видны, а глобальные внутри не видны автоматически. Передавайте данные параметрами.

## Полезные функции

```php
count($array);                       // число элементов в массиве

```

## Массивы, которые мы используем

Каждый товар — ассоциативный массив (ключ => значение). Вся коллекция —

массив таких массивов (многомерный массив):

```php
$catalog = [
    ['title' => 'Ноутбук', 'price' => 54990, 'stock' => 12, 'discount' => 10],
];
// обращение: $catalog[0]['title'], $catalog[0]['price']
```
