# Работа 2. Массивы и функции

Конспект по теме. Всё демонстрируется на примерах из задания — каталога товаров.

## Виды массивов

**Индексированный** — ключи 0, 1, 2…:

```php
$colors = ['красный', 'зелёный', 'синий'];
echo $colors[0];       // красный
$colors[] = 'белый';   // добавить в конец
```

**Ассоциативный** — свои ключи:

```php
$product = [
    'title'  => 'Ноутбук',
    'price'  => 54990,
    'stock'  => 12,
];
echo $product['title'];  // Ноутбук
```

**Многомерный** — массив массивов (наш каталог):

```php
$catalog = [
    ['title' => 'Ноутбук', 'price' => 54990],
    ['title' => 'Мышь',    'price' => 1290],
];
echo $catalog[1]['title'];   // Мышь
```

## Базовые операции с массивами

```php
count($catalog);                        // сколько элементов
in_array('Мышь', $names, true);         // есть ли значение (true = строгая проверка)
array_push($items, $x);                 // то же, что $items[] = $x;
array_pop($items);                      // убрать последний
array_key_exists('price', $product);    // есть ли ключ
array_keys($product);                   // все ключи
array_values($catalog);                 // все значения (ключи 0,1,2…)
array_slice($items, 0, 3);              // срез: 3 элемента с 0-го
array_column($catalog, 'price');        // столбец 'price' из всех строк (удобно для сортировки и проверок)
implode(', ', $names);                  // массив -> строка
explode(', ', 'a, b');                  // строка -> массив
```

## Цикл foreach по «строкам» таблицы

```php
foreach ($catalog as $product) {
    // внутри $product — один товар (ассоциативный массив)
}
```

Важно: `foreach` меняет списочный ключ (0,1,2), а если массив достали из JSON и он
содержал ключи — порядок сохраняется, но ключи остаются. Поэтому если нужен
«честный» переиндексированный список с ключами 0,1,2 — используйте `array_values()`.

## Встроенные функции-циклы

Часто проще один раз выучить функции, чем писать циклы вручную:

```php
array_map($callback, $array);                  // применить callback к каждому элементу
array_filter($array, $callback);               // оставить элементы, где callback вернул true
usort($array, $callback);                      // сортировка по своему правилу
```

Пример сортировки через `usort`:

```php
usort($catalog, function (array $a, array $b) {
    return $a['price'] <=> $b['price'];        // оператор корабль сравнения
});
```

Оператор `<=>` возвращает −1, 0 или 1 — именно то, что ждёт `usort`.

## Функции — подробнее

```php
// параметр со значением по умолчанию
function filter_by_price(array $catalog, float $min = 0.0, ?float $max = null): array
{
    ...
}

// настоятельный: вы должны вернуть массив (тип после =>)
```

- параметру можно задать тип: `array $catalog`, `float $min`;
- `?float $max` — параметр может быть `null` или числом;
- `: array` — обязательный тип результата;
- переменные, объявленные внутри функции, наружу не видны; снаружи — не видны внутри;
  всё, что нужно, передавайте параметрами;
- `return` прерывает функцию и возвращает значение;
- `use ($direction)` внутри анонимной функции — способ «прокинуть» внешнюю переменную.

## Тонкость: сортировка не теряет данные

`usort` меняет массив «на месте» (по ссылке), а мы возвращаем тот же массив из
функции. Если передать `$catalog` напрямую — исходный каталог «испортится».
Поэтому сначала копируем массив в `sort_by_price()` — присваивание массива в PHP
само копирует его (copy-on-write), менять можно смело.

## Пагинация одной функцией

```php
$paged = paginate($catalog, $page, $perPage);
// $paged['items']      — товары текущей страницы
// $paged['total']      — сколько всего
// $paged['page']       — текущая страница (уже исправленная)
// $paged['totalPages'] — сколько страниц
```

Текущая страница «зажимается» в диапазон `1..totalPages` — это защищает
от выхода за границы при ручном вводе `?page=999`.
