Работа 1. Каталог товаров — первые шаги

Цель

Познакомиться с базовыми конструкциями PHP: переменные, типы данных, операторы, условия, match и циклы. Результат — «живая» таблица каталога товаров с расчётом скидок и итогов по складу.

Задание

  1. Создайте массив $catalog из не менее 6 товаров. У каждого товара обязательные поля:
    • title — название (строка);
    • category — категория (строка);
    • price — цена в рублях (целое);
    • stock — остаток на складе (целое, 0 допустимо);
    • discount — скидка в процентах (целое, от 0 до 100).

    Пример категорий: «Техника», «Аксессуары», «Игры».

  2. Напишите функцию price_with_discount(int $price, int $discount): float, которая возвращает цену со скидкой, округлённую до 2 знаков после запятой. Скидка 0 — цена не меняется.
  3. Напишите функцию stock_label(int $stock): string через match:
    • 0 → 'Нет в наличии';
    • от 1 до 5 включительно → 'Мало';
    • больше 5 → 'В наличии'.
  4. Выведите таблицу каталога циклом for, используя:
    • count($catalog) для количества строк;
    • number_format(..., 0, ',', ' ') для цены и скидки;
    • stock_label() в колонке «Остаток».
  5. Отдельным циклом foreach посчитайте итоговую стоимость всего склада (сумма цена со скидкой × остаток по каждому товару) и количество товаров со скидкой. Выведите оба числа под таблицей.
  6. Продемонстрируйте любой пример на while (например, выведите число строк отсчётом от 5 до 1 перед таблицей).

Запуск

php solution.php     # эталонное решение
php test.php         # автотесты (должны пройти все)

Критерии приёмки

  • php test.php завершается без ошибок (в конце «ошибок: 0»);
  • в таблице есть все товары из каталога;
  • цены со скидкой посчитаны верно (проверьте на калькуляторе 1–2 строки вручную);
  • в категории «Мало» у товара остаток от 1 до 5, «Нет в наличии» — 0;
  • итоговая стоимость склада совпадает с ручным расчётом.
