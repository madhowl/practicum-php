Работа 2. Каталог товаров — массивы и функции

Цель

Научиться обрабатывать многомерные массивы с помощью процедурных функций: фильтровать по категории и цене, искать по названию, сортировать и резать каталог на страницы. Это фундамент витрины из работ 3–5.

Задание

Используйте каталог из работы 1 (или свой). Напишите функции:

  1. filter_by_category(array $catalog, ?string $category): array
    Возвращает только товары выбранной категории. Значения null, '' или 'all' означают «весь каталог».
  2. filter_by_price(array $catalog, float $min = 0.0, ?float $max = null): array
    Возвращает товары, у которых price в диапазоне [min, max] включительно. Если $max = null — верхней границы нет.
  3. search_by_name(array $catalog, string $query): array
    Ищет товары, в названии которых встречается подстрока $query. Поиск без учёта регистра (пригодится mb_strtolower и str_contains). Пробелы по краям запроса не важны, пустой запрос — весь каталог.
  4. sort_by_price(array $catalog, string $direction = 'asc'): array
    Сортирует по цене: 'asc' — от дешёвых к дорогим, 'desc' — наоборот. Массив, переданный снаружи, менять нельзя.
  5. sort_by_title(array $catalog, string $direction = 'asc'): array
    Сортирует по названию по алфавиту (без учёта регистра).
  6. paginate(array $items, int $page, int $perPage): array
    Возвращает массив с ключами items, total, page, totalPages. Номер страницы «зажимайте» в диапазон от 1 до последней.
  7. unique_categories(array $catalog): array
    Возвращает список категорий каталога без повторов.
  8. Напишите небольшую демонстрацию, которая применяет каждую функцию к каталогу и печатает результат (как в solution.php).

Подсказки

  • Для сортировки используйте usort() и оператор <=>.
  • Для пагинации — array_slice() и ceil().
  • Для уникальных категорий — ключи ассоциативного массива.
  • Сначала копируйте каталог в локальную переменную перед сортировкой.

Запуск

php solution.php     # эталонное решение
php test.php         # автотесты

Критерии приёмки

  • php test.php завершается с «ошибок: 0»;
  • фильтры не «теряют» товары других категорий;
  • поиск находит строки на русском и без учёта регистра;
  • сортировка в обе стороны работает, исходный массив не изменился;
  • пагинация корректно отрабатывает страницы 0, 1 и слишком большие номера.
