Работа 6. Каталог товаров — ООП

Цель

Переписать логику каталога из работы 5 на классы. Данные и поведение товара должны жить вместе, категория стать строгим типом, а ошибки — обрабатываться предсказуемо. Внешне приложение остаётся тем же CRUD-каталогом, но внутри всё устроено по-объектному.

Что должно получиться

pr6/
├── test.php           // автотесты (уже есть)
├── composer.json      // правило автозагрузки PSR-4
├── src/               // ВАШИ классы (создаёте вы)
│   ├── Category.php
│   ├── Product.php
│   ├── ProductValidator.php
│   ├── Catalog.php
│   ├── StorageInterface.php
│   ├── JsonFileStorage.php
│   ├── CatalogRepository.php
│   ├── Html.php
│   ├── ProductNotFoundException.php
│   ├── StorageException.php
│   └── InvalidArgumentException.php
├── bootstrap.php      // подключает vendor/autoload.php
├── layout.php         // общие HTML-обёртки
├── index.php add.php edit.php delete.php
├── data/catalog.json  // создаётся само
└── vendor/            // автозагрузчик от Composer

Важно про имена файлов. Автозагрузка работает по правилу «имя класса = путь к файлу»: класс App\Product лежит в src/Product.php.

После каждого шага запускайте php test.php — в конце должно быть «ошибок: 0».

Шаг 0. Автозагрузка через Composer

Подключать одиннадцать файлов вручную через require неудобно. Доверим автозагрузку Composer: он сгенерирует её по правилу PSR-4.

1. Создайте в папке pr6 файл composer.json с правилом PSR-4:

{
    "autoload": {
        "psr-4": {
            "App\\": "src/"
        }
    }
}

2. Выполните установку — появится папка vendor/ и файл-автозагрузчик:

composer install

3. Создайте bootstrap.php, который подключает готовый автозагрузчик:

require __DIR__ . '/vendor/autoload.php';

После этого класс App\Product подключается из src/Product.php автоматически. Папку vendor/ не редактируют руками и не коммитят — она воспроизводится командой composer install.

Шаг 1. Category — перечисление

enum Category: string
{
    case Tech = 'Техника';
    case Games = 'Игры';
    case Accessories = 'Аксессуары';

    public function label(): string;          // название для человека
    public static function labels(): array;   // ['Техника', 'Игры', 'Аксессуары']
}
Category::Tech->value;      // Техника
Category::Games->label();   // Игры
Category::from('Аксессуары');   // Category::Accessories
Category::tryFrom('Ерунда');    // null

Шаг 2. Product — товар

final class Product
{
    public function __construct(
        public readonly int $id,
        public readonly string $title,
        public readonly Category $category,
        public readonly float $price,
        public readonly int $stock,
        public readonly int $discount,
    );

    public function priceWithDiscount(): float;   // цена со скидкой
    public function stockLabel(): string;          // метка наличия
    public function toArray(): array;              // -> массив для JSON
    public static function fromArray(array $row): self;   // массив -> объект
    public function __toString(): string;          // '#3 Ноутбук — Техника'
}
  • в конструкторе проверьте инварианты и бросьте InvalidArgumentException: цена < 0, остаток < 0, скидка вне 0..100;
  • priceWithDiscount(): round($price * (100 - $discount) / 100, 2);
  • stockLabel(): через match (true) — 0 «Нет в наличии», 1..5 «Мало», иначе «В наличии»;
  • toArray(): ключи id, title, category, price, stock, discount (категория — строкой);
  • fromArray(): приводите типы, категорию через Category::tryFrom(...) ?? Category::Tech.
$product = new Product(3, 'Наушники JBL Tune', Category::Accessories, 3990.0, 30, 20);
echo $product->priceWithDiscount();   // 3192.0
echo $product->stockLabel();          // В наличии

Шаг 3. ProductValidator

final class ProductValidator
{
    /** @return array<string, string> */
    public function validate(array $input): array;
}

Правила — как в работе 3: название непустое и не короче 3 символов; категория из списка; цена — число больше нуля; остаток — число не меньше нуля; скидка — от 0 до 100. Ключ ошибки — имя поля формы, а пустой массив означает «всё хорошо».

Шаг 5. JsonFileStorage

final class JsonFileStorage implements StorageInterface
{
    public function __construct(private readonly string $file);
    public function load(): array;            // ВСЕГДА массив товаров
    public function save(array $rows): void;  // при сбое — StorageException
    private function recover(): array;
    public static function defaultCatalog(): array;   // 8 товаров
}

Логика из работы 4: нет файла → дефолт; json_validate не прошёл или не список → переименовать в .broken.<дата> и взять дефолт; запись — json_encode с JSON_PRETTY_PRINT | JSON_UNESCAPED_UNICODE и LOCK_EX.

Шаг 6. Catalog — коллекция

final class Catalog implements Countable, IteratorAggregate
{
    public function __construct(array $products = []);
    public function count(): int;
    public function getIterator(): Traversable;

    public function all(): array;
    public function isEmpty(): bool;
    public function find(int $id): ?Product;
    public function nextId(): int;

    public function add(Product $product): void;
    public function update(Product $product): void;    // бросит исключение
    public function delete(int $id): void;             // бросит исключение

    public function search(string $query): self;
    public function filterByCategory(Category $category): self;
    public function sortByPrice(string $direction = 'asc'): self;
    public function sortByTitle(): self;
    public function sortByStock(string $direction = 'desc'): self;

    public function paginate(int $page, int $perPage): array;
    public function stats(): array;
}
  • внутри — private array $products; вход в конструкторе прогнать через array_values;
  • search, filterByCategory, sortBy* возвращают новый Catalog — так методы строятся в цепочку;
  • paginate() возвращает items, page, perPage, totalPages, total, страницу зажать в границы [1, totalPages];
  • stats() — products, stock, warehouse, discounted.
$found = $catalog->search('игр')->filterByCategory(Category::Games)->sortByPrice('desc');

Шаг 7. CatalogRepository

final class CatalogRepository
{
    public function __construct(private readonly StorageInterface $storage);
    public function load(): Catalog;
    public function save(Catalog $catalog): void;
    public function find(int $id): Product;                  // бросит исключение
    public function create(array $input): Product;
    public function update(int $id, array $input): Product;  // бросит исключение
    public function delete(int $id): void;                   // бросит исключение
}

load(): строки из хранилища → Product::fromArray() → new Catalog(). save(): toArray() по всем товарам → storage->save(). create() берёт новый id у $catalog->nextId().

Шаг 9. Страницы приложения

app.php — единая сборка:

require __DIR__ . '/bootstrap.php';

const PER_PAGE = 5;

$storage = new JsonFileStorage(__DIR__ . '/data/catalog.json');
$repository = new CatalogRepository($storage);
$validator = new ProductValidator();

layout.php — функции page_header(), page_footer(), banner(), flash_message(), query_url(), product_form().

  • index.php: search → filterByCategory → sortBy* → paginate, таблица, пагинация, сообщения;
  • add.php: GET — форма; POST — валидация, при успехе create() и редирект index.php?added=N;
  • edit.php?id=N: find() в try, в catch (ProductNotFoundException) — 404; при успехе — редирект;
  • delete.php?id=N: GET — подтверждение, POST — удаление и редирект index.php?deleted=N.

Все выводы — только через Html::e(); id берётся как $id = (int) ($_GET['id'] ?? 0);.

Запуск

composer install                # один раз: создаст vendor/autoload.php
php test.php                    # автотесты (классы ищет в src/)
php -S localhost:8000 -t .      # сайт: http://localhost:8000/index.php

Критерии приёмки

  • composer install проходит и создаёт vendor/autoload.php;
  • php test.php завершается с «ошибок: 0» и кодом 0;
  • в src/ есть все классы, имена файлов совпадают с классами (PSR-4);
  • добавление → товар в файле и списке;
  • редактирование → изменения видны, id не изменился;
  • удаление → товар исчез, есть сообщение «удалён»;
  • edit.php?id=999 отдаёт 404 и текст «Товар #999 не найден»;
  • поиск, фильтр и пагинация не «слетают» при переходе по страницам;
  • цена-текст показывает ошибку под полем и не теряет введённое;
  • категория — это Category, а не строка; в коде нет $product['title'].
