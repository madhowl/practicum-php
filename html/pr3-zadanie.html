Работа 3. Каталог товаров — строки и формы

Цель

Научиться обрабатывать данные из веб-форм: поиск и фильтры через $_GET, добавление товара через $_POST, валидация ввода, безопасный вывод (htmlspecialchars).

Задание

Создайте страницу каталога (в functions.php — чистые функции, в index.php — логика и HTML):

  1. Поиск по названию — поле, шлёт методом GET. Поиск без учёта регистра, пробелы по краям не важны, пустой запрос показывает весь каталог.
  2. Фильтр по категории — выпадающий список, тоже GET. Значение all — все категории.
  3. Таблица каталога — как в работе 1, но в HTML: название, категория, цена, скидка, цена со скидкой, метка наличия. Всё, что выводится, — через e().
  4. Форма добавления товара (POST) с полями: название, категория (select), цена, остаток, скидка. При ошибках валидации:
    • показать сообщение под соответствующим полем;
    • не потерять то, что пользователь уже ввёл.
  5. Валидация (validate_product()):
    • название — не пустое и не короче 3 символов;
    • категория — выбрана;
    • цена — число и больше нуля;
    • остаток — число, не меньше нуля;
    • скидка — число от 0 до 100.
  6. sanitize_product() — приводит валидные данные к «чистому» товару с нужными типами (убирает пробелы, делает (float)/(int)).
  7. Если форма прошла валидацию — покажите зелёное сообщение «товар прошёл валидацию» и добавьте его первой строкой таблицы (сохранение появится в работе 4).

Пометки

  • Храните каталог в data.php, который return-ит массив.
  • Всё, что пришло от пользователя и попадёт в HTML (включая значения полей формы), выводите только через e().
  • Чистые функции (валидация, поиск, фильтры) держите в functions.php — так их легко тестировать в test.php.

Запуск

php test.php                          # автотесты функций
php -S localhost:8000 -t pr3          # браузер: http://localhost:8000/index.php

Критерии приёмки

  • php test.php завершается с «ошибок: 0»;
  • поиск «игр» находит приставку и настольную игру, «науш» — наушники;
  • форма со скидкой 150 покажет ошибку, цена «ноль» — ошибку;
  • при отправке с ошибкой введённые значения не теряются;
  • в HTML нет ни одного вывода $p['title'] без e() (посмотри глазами код);
  • после успешной отправки видно сообщение и товар в таблице.
