Практикум по PHP 8.3

Пять практических работ по основам PHP, выполненных в чисто процедурном стиле (без классов и ООП). Каждая работа — самостоятельный, проверяемый этап; вместе они образуют один сквозной проект — веб-витрину «Каталог товаров» с хранением данных в JSON-файле.

О чём курс

  • базовые конструкции языка: переменные, типы, условия, циклы, match;
  • процедурный подход: функции, работа с массивами, поиск, сортировка, пагинация;
  • веб-часть: формы GET/POST, валидация, безопасный вывод;
  • файлы и JSON: json_encode/json_decode, json_validate (новое в PHP 8.3), обработка ошибок;
  • итоговое приложение: полный CRUD над данными в JSON-файле.
Требования к окружению PHP 8.3+ (php -v) и расширение mbstring (php -m | grep mbstring). Никаких composer, фреймворков и БД не требуется.

Быстрый запуск

Тесты всех работ 
php pr1/test.php
php pr2/test.php
php pr3/test.php
php pr4/test.php
php pr5/test.php

В конце каждой проверки — «ошибок: 0».

Итоговое приложение 
php -S localhost:8000 -t pr5

Открыть localhost:8000/index.php. Работы 3–4 запускаются аналогично: -t pr3, -t pr4.

Консольные демо 
php pr1/solution.php
php pr2/solution.php

Работы 1–2 выводят результат в терминал.

Исходный код и автотесты лежат в папках pr1…pr5 рядом с этим сайтом. Данные приложение хранит в pr4/data/catalog.json и pr5/data/catalog.json: если файл удалить или испортить, приложение само восстановит каталог по умолчанию.
